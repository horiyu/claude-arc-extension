# Claude in Arc

Arc ブラウザ向けの Claude 拡張機能です．
Claude と会話しながら，ブラウザの自動操作，タスクのスケジュール実行，ファイル操作などが行えます．

## インストール・セットアップ

1. Arc を開き，アドレスバーに `arc://extensions` と入力
2. 右上の「デベロッパーモード」を有効化
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このリポジトリを選択
5. ツールバーの Claude アイコンをクリック
6. Split View でサイドパネルにするなどしてお好みのレイアウトに
